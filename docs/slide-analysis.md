## 설득 흐름
1. **이해** - 내 데이터 기반 분석이구나
2. **불편한 자각** - 부족하네 / 수익률이 높아야 하네 / 자산이 먼저 떨어지네
3. **구조적 복잡성 인식** - 매년 관리할 게 많네 / 연금도 복잡하네 / 질문이 많네
4. **자연스러운 결론** - 혼자 하기엔 비효율적이다 / 맡기면 결정만 하면 되겠다

## 핵심 설득 포인트

1. **문제 인식 유도**
   - 은퇴 후 현금흐름 Gap
   - 자산 소진 시점 < 기대수명
   - 높은 필요수익률

2. **복잡성 강조**
   - 3층 연금 구조
   - 매년 관리해야 할 6가지
   - 매년 답해야 할 5가지 질문

3. **전문가 필요성**
   - "혼자서 모든 것을 관리하기 어렵습니다"
   - 역할 분담: 고객은 결정만, 나머지는 전문가

4. **행동 유도**
   - 겁주기 X → 비효율성 인식 O
   - "맡기면 편하다"는 자연스러운 결론
